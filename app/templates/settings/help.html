DocIndex Help

Your personal, searchable file drive: upload documents and images, let the indexer extract their text, find anything in seconds, and ask the AI assistant questions about your own files.

{% call section('help-drives', 'fa-hard-drive', 'Drives') %}

Drives are separate vaults that group your files — like multiple disks. Everyone starts with a Personal drive; create more from the drive dropdown in the top bar (e.g. "Work", "Photos", "Archive").

The dropdown switches the current drive: uploads, search, the AI chat and the file browser all work inside it. The same file can exist in different drives — duplicates are detected per drive, never across drives.

{% endcall %} {% call section('help-upload', 'fa-cloud-arrow-up', 'Uploading & organizing') %}

Use the upload button (or drag & drop files onto the drive page) to add files. Create folders to organize them. Supported content: text files, PDFs, Word documents and images.

After upload, each file is indexed in the background: text is extracted (OCR for images), stats are computed and — if enabled — the AI writes an image caption. The badge next to each file shows the state: pending ok error. The profile page shows the live indexing queue.

{% endcall %} {% call section('help-search', 'fa-magnifying-glass', 'Search') %}

The search bar in the top bar searches the current drive: file names, extracted text, AI captions and hashtags, ranked by relevance (FTS5 + BM25). Words match by prefix — read also finds README.md.

Results show a highlighted snippet and badges telling where the match was found (name, tags, caption, content). Use the eye icon to preview or the arrow to download.

{% endcall %} {% call section('help-file-view', 'fa-file-lines', 'The file view') %}

Click any file to open its page: preview, download, rename, edit text files in place, word/line/char counts, hashtags and — for images — the AI caption. Every content change is indexed again automatically.

Deleting a file moves it to the trash (see below) — nothing is lost until you purge it.

{% endcall %} {% call section('help-versions', 'fa-clock-rotate-left', 'Version history') %}

Every file keeps a history: uploading a file with the same name in the same folder, or editing its content, creates a new version instead of destroying the old one. Open History in the file view to compare versions side by side (text diff) or download an older version of a binary file, and restore any version with one click.

{% endcall %} {% call section('help-hashtags', 'fa-hashtag', 'Hashtags') %}

Hashtags make search faster and more precise. Add them manually in the file view (the chip editor), or click Create Hashtags: the AI reads the file and suggests tags in a small review popup — remove the ones you dislike and only then apply them.

To tag a whole drive at once, use the bulk hashtag job on the profile page (with pause/resume and its own worker limit, respecting your connection's rate limit). The AI assistant also searches by hashtags first (tags: scope), so tagged files answer faster.

{% endcall %} {% call section('help-duplicates', 'fa-clone', 'Duplicates') %}

Uploading content identical to an existing file (same SHA-256) in the same drive is flagged: the file view shows the duplicates and lets you merge them — the merged file keeps the combined version history, so nothing is lost.

{% endcall %} {% call section('help-trash', 'fa-trash', 'Trash bin') %}

Deleted files go to the trash (profile page → Trash). From there you can restore them to their original folder or purge them permanently (this also deletes versions and thumbnails). A confirmation dialog always asks before anything is destroyed.

{% endcall %} {% call section('help-sync', 'fa-arrows-rotate', 'Synced drives (local folders)') %}

A synced drive mirrors a real folder on this computer. Create one from the drive dropdown → "Sync a local folder" and paste the path. Everything inside is indexed and searchable — but read-only: files in it cannot be edited, renamed or deleted in DocIndex, and removing the drive never touches the real folder.

Syncs run on demand (Sync now on the profile page or the drive view), with live progress in the bottom-right widget and on the profile card — you can pause, resume or stop a running sync. Per synced drive you can choose the number of indexing workers and toggle AI image captions. Changed files are re-indexed, vanished files are removed from the drive, and the last-sync stats (+added / updated / −removed / skipped) stay on the card.

{% endcall %} {% call section('help-ai-chat', 'fa-robot', 'AI assistant chat') %}

The robot button (or Alt+A) opens a chat window that answers questions about your files: the assistant searches, counts, reads and cross-references them step by step, and shows its work — expand Reasoning to see what it is doing and which tools it called. Answers cite sources as clickable file links.

  • Multiple windows — the clone button opens parallel chats; drag windows by the header, resize from the corner grip.
  • Attachments — Current file attaches the file open in the viewer; Search files (or typing #) finds files to attach; you can also drop files onto the window.
  • Model selector — switch between your AI connections from the header dropdown.
  • Conversations — the clock button lists past conversations; reopen or delete them there.
  • Stop — while the assistant works, the send button becomes a red stop button that cancels the answer.
  • Summarize & reset — the compress button asks the AI to condense the whole conversation into a summary. Old messages stay visible (grayed out, under a "History compacted" divider) but leave the model's context — the summary becomes the memory. Perfect for long sessions and small models.
{% endcall %} {% call section('help-ai-search', 'fa-wand-magic-sparkles', 'AI search page') %}

From the home/search page, switch the toggle from Search to AI: your question is answered in natural language with the sources it used. It is the same assistant as the chat, in a full-page layout — attachments and stop work the same way.

{% endcall %} {% call section('help-profile', 'fa-user', 'Profile page') %}

Your profile centralizes everything about your account:

  • Account details — change email and password.
  • Drive cards — files, folders, space used and indexed words per drive; synced drives also show sync controls and stats.
  • AI usage — conversation and message counts and the active connection.
  • Indexing queue — live progress of background indexing, with pause/resume.
  • Error logs — every warning and error the app records (AI, database, indexing…), in a searchable table, with CSV export to share with support.
  • Trash — restore or purge deleted files.
  • Admins can additionally enable or disable new registrations on the login page.
{% endcall %} {% call section('help-ai-settings', 'fa-gear', 'AI settings') %}

DocIndex talks to any OpenAI-compatible provider (Ollama, LM Studio, OpenAI, Anthropic, Kimi…). Add a connection with base URL, model and API key — presets fill the well-known providers — and use Test connection to validate it. The first connection activates automatically; the active one is used everywhere.

Per-connection knobs (empty = global default):

  • Vision model — used for image captions.
  • Max agent steps — how many search/read steps the assistant may take per question (default 16).
  • Requests per minute — rate limit for providers that throttle (0 = unlimited).
  • History messages — how many past chat messages are sent to the model (default 20).
  • Prompt budget — maximum estimated prompt size in tokens (default 60 000). Set it below your model's context window; older messages are dropped when a conversation would exceed it.

{% endif %} {% call section('help-troubleshooting', 'fa-screwdriver-wrench', 'Troubleshooting') %}
  • "Conversation too large for the context window" — use Summarize & reset, start a new conversation, or lower the prompt budget / history messages in AI Settings.
  • OCR warnings — image text extraction needs Tesseract installed on the server; without it images are still searchable by name, caption and hashtags.
  • Search finds nothing after an upgrade — run flask --app run.py reindex-fts to rebuild the search index.
  • AI not responding — check the connection with the Test button in AI Settings, and look at the error logs on the profile page for the exact cause.
